# Contributing to uuid

Thank you for your interest in contributing to this project! By participating, you agree to abide by the terms outlined below.

---

## 🛠️ How to Contribute

1. **Fork** the repository
2. **Create a branch** for your feature or fix
3. **Make your changes** and ensure all tests pass
4. **Submit a Pull Request** with a clear description

### Before Submitting

```bash
make format          # Format code
make lint            # Check for lint errors
make test            # Run unit tests
make benchmark       # Ensure no performance regression
make fuzz            # Run fuzz tests
```

## 🔍 Code Review Process

1. All submissions require review before merging
2. Maintainers may request changes or improvements

## 💡 Guidelines

- Follow existing code style and conventions
- Write clear commit messages
